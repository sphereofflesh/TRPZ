================================================================================
 СИСТЕМА ОБЛІКУ ЕНЕРГОРЕСУРСІВ ОСББ — РЕЛІЗНИЙ ПАКЕТ v1.0.0
================================================================================

1. СКЛАД ПАКЕТА:
  - api/      : Скомпільований сервер Web API (.NET 8.0, Labka.dll)
  - client/   : Скомпільований консольний клієнт (.NET 8.0, Labka.Client.dll)
  - INSTRUCTIONS.txt : Ця інструкція

2. ВИМОГИ:
  - Встановлений .NET Runtime 8.0 або .NET SDK 8.0 (dotnet CLI)

3. ЗАПУСК СЕРВЕРА (Термінал 1):
  dotnet api/Labka.dll --urls "http://localhost:5052"

  Сервер запуститься та слухатиме порт 5052.
  Swagger документація доступна за адресою: http://localhost:5052/swagger

4. ЗАПУСК КЛІЄНТА (Термінал 2):
  API_BASE_URL="http://localhost:5052/" dotnet client/Labka.Client.dll

  У вікні клієнта відкриється інтерактивне консольне меню:
  - Пункт 1: перегляд усіх лічильників
  - Пункт 2: реєстрація лічильника (UC-02)
  - Пункт 3: внесення показника (UC-01)
  - Пункт 4: історія показників (UC-04)
  - Пункт 5: розрахунок споживання (UC-05)
  - Пункт 6: виведення з експлуатації (UC-03)
  - Пункт 7: автоматична демонстрація всіх сценаріїв

5. ВАЖЛИВЕ ОБМЕЖЕННЯ (v1.0):
  Дані зберігаються виключно в оперативній пам'яті сервера (In-Memory).
  Після завершення процесу сервера всі внесені дані скидаються.
