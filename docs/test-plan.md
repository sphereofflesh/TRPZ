# Тест-план та протокол приймального тестування (v1.0.0)

## 1. Загальний опис

Тест-план охоплює функціональне, інтеграційне та регресійне тестування першої версії програмного продукту «Система обліку енергоресурсів ОСББ» (v1.0.0).  
Перевірці підлягають:
- Серверна частина: ASP.NET Core Web API (`Labka`).
- Клієнтська частина: інтерактивний консольний клієнт (`Labka.Client`).
- In-Memory сховище даних та потокобезпека доступу (`lock`).

## 2. Середовище тестування

- **ОС:** Linux (Ubuntu 24.04 LTS / POSIX x64)
- **Платформа:** .NET SDK 8.0.428 (.NET 8.0)
- **Фреймворк тестування:** xUnit 2.9.2, Microsoft.NET.Test.Sdk 17.11.1, Microsoft.AspNetCore.Mvc.Testing 8.0.11
- **Адреса сервера:** `http://localhost:5052/`
