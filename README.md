# Система обліку енергоресурсів ОСББ (v1.0.0)

---

## 1. Склад проєкту

- **`Labka`** — серверна частина (ASP.NET Core Web API, .NET 8.0). Забезпечує REST API, валідацію предметних правил (`ReadingRules`), обробку відмов та збереження об'єктів у потокобезпечній колекції оперативної пам'яті (`InMemoryEnergyStore`).
- **`Labka.Client`** — клієнтський консольний застосунок (.NET 8.0). Забезпечує інтерактивну взаємодію з сервером через українське меню, читання та відображення відповідей, а також повноцінний режим автодемонстрації погоджених сценаріїв.
- **`tests/Labka.Tests`** — набір автоматичних модульних та інтеграційних тестів (xUnit, 27 тестів, 100% успішність).
- **`docs/`** — повний пакет інженерної документації:
  - `requirements.md` — базова лінія вимог (SRS v1.0);
  - `use-cases.md` — специфікації сценаріїв та Activity-діаграма;
  - `design.md` — початкова проєктна модель, **командна діаграма класів фактичної реалізації (Mermaid)** та порівняльний аналіз;
  - `sequences/` — **індивідуальні діаграми послідовностей**:
    - `UC-01-reading-sequence.md` (Ткаченко Богдан — внесення показника та обробка відмов);
    - `UC-02-register-sequence.md` (Трофименко Арсеній — реєстрація лічильника);
    - `UC-05-consumption-sequence.md` (Трофименко Арсеній — розрахунок споживання);
  - `traceability.md` — **актуалізована матриця простежуваності вимог (RTM)**;
  - `test-plan.md` — план та фактичний протокол приймального тестування;
  - `implementation-plan.md` — план виконання задач та протокол рецензування;
  - `team.md` — розподіл ролей у команді.
- **`artifacts/v1.0.0/`** — бінарні артефакти першого перевіреного випуску v1.0.0 та архів `.tar.gz`.

## 2. Реалізовані можливості (v1.0.0)

1. **UC-01 / FR-01: Внесення показника лічильника** з повною валідацією хронології дати й незменшення значення (NFR-02).
2. **UC-02 / FR-02: Реєстрація нового лічильника** (номер, тип, адреса встановлення, коефіцієнт).
3. **UC-03 / FR-03: Виведення лічильника з експлуатації** (статус `Decommissioned`, блокування подальшого внесення).
4. **UC-04 / FR-04: Перегляд історії показників** у хронологічному порядку.
5. **UC-05 / FR-05: Точний розрахунок споживання** за обраний період із урахуванням тарифного коефіцієнта.

---

## 3. Обмеження першої версії (In-Memory Storage)

> [!WARNING]
> **Увага (обмеження v1.0):** Робочі дані (лічильники та їхні показники) зберігаються виключно в **оперативній пам'яті сервера** (`InMemoryEnergyStore`) протягом часу роботи серверного процесу.
> Під час завершення або перезапуску процесу сервера всі додані користувачами записи **автоматично анулюються**, і сховище ініціалізується початковим станом (демонстраційний лічильник `EL-2026-001`).

## 5. Інструкція запуску з вихідного коду

### Крок 1. Клонування та відновлення залежностей

```bash
git clone https://github.com/sphereofflesh/TRPZ.git
cd TRPZ
dotnet restore Labka.sln
```

### Крок 2. Запуск сервера (Web API)

У першому терміналі:
```bash
dotnet run --project Labka --urls "http://localhost:5052"
```

Сервер стане доступним за адресою: `http://localhost:5052`  
Документація Swagger UI: `http://localhost:5052/swagger`  
Перевірка працездатності: `http://localhost:5052/health`

### Крок 3. Запуск консольного клієнта

У другому терміналі:
```bash
dotnet run --project Labka.Client
```

Якщо сервер запущено на іншій адресі чи порту, передайте змінну середовища:
```bash
API_BASE_URL="http://localhost:5052/" dotnet run --project Labka.Client
```

### Крок 4. Автоматизована демонстрація через клієнт

У меню клієнта оберіть пункт:
```text
7. Запустити повну демонстрацію сценаріїв (UC-01..UC-05)
```
Клієнт послідовно виконає:
- реєстрацію лічильника (UC-02);
- успішні внесення показників 1200 та 1260 (UC-01);
- перевірку відмов: раніший час (код 409 `invalid_date`) та менше значення (код 409 `lower_value`);
- підтвердження незмінності історії після відмов;
- розрахунок споживання: `(1260 - 1200) * 1.5 = 90.0 кВт·год` (UC-05);
- виведення з експлуатації (UC-03) та блокування нових показників.

dotnet artifacts/v1.0.0/api/Labka.dll --urls "http://localhost:5052"

API_BASE_URL="http://localhost:5052/" dotnet artifacts/v1.0.0/client/Labka.Client.dll
